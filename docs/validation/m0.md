## 当前工具用法

PowerShell（在项目根目录）：

```powershell
$env:GOCACHE = Join-Path (Get-Location) 'local/go-cache'
$env:GOTMPDIR = Join-Path (Get-Location) 'local/go-tmp'
New-Item -ItemType Directory -Force $env:GOCACHE,$env:GOTMPDIR,'dist','local/validation' | Out-Null
go test -v ./...
go vet ./...
go build -o dist/d2core.exe ./cmd/d2core
./dist/d2core.exe m0-inspect
```

输入齐全后传 `--executable`、`--working-directory`、`--cfg-directory`、`--vpk`、`--gameinfo`、`--version-file`，每个值使用本平台绝对路径，包含空格时加引号。每个文件会完整读取计算 SHA256，大 VPK 需要时间。目录只检查可打开及类型，不做写测试。符号链接会记录解析目标，实机写入前另行核对归属。

JSON 写 stdout，错误写 stderr。显式提供的错误路径返回非零；缺少输入返回清单而不假装引擎通过。`suppliedInputsValid=true` 仅表示已提供项没有静态错误，空输入也可以成立。该工具的格式属于 M0 实验，不是正式管理 API。

Ubuntu 待授权后，在可写隔离目录用原生 Go 执行 `go test -v ./...`，或执行对应架构的交叉构建测试二进制（记录工具链、系统和架构）。不得将 GitHub 的 ubuntu-latest 或本地交叉构建当成目标 Ubuntu 24 实机证据。

## Windows 引擎探针边界

`tools/m0/windows-engine.ps1` 运行于 PowerShell 7，接收绝对 RunDirectory 与本地 input.json。`launch` 使用参数数组直接创建程序，不经 shell 拼接；唯一 cfg 以 CreateNew 写入。先保存 intent，已有 intent 拒绝重复启动，防止记录中断后盲目再次派生。该机制只阻止相同实验目录重试，不是正式全局恢复机制。

`observe` 重新打开同一进程句柄，核验程序路径和创建时间。首次观测因 PowerShell 自动将 JSON 时间转为 DateTime 而安全拒绝；已修复为统一 UTC 后比较，正例与修改时间的负例均实测通过。PID 重用、整机重启、身份缺失窗口仍待专项测试。

`force-stop` 仅终止经核验的单个测试进程，保留 cfg/日志和退出记录，不声称清理子进程或释放所有端口；run01 已执行并确认进程消失、该 PID 的套接字不再存在。优雅停止候选见下文，不将单个强制停止探针直接作为生产停止实现。实机清理必须另行核验 cfg 归属与内容，不能批量删除安装中的文件。

`windows-quit.ps1` 是新增的 Windows 正常退出实验：固定只发 quit；持有核验进程句柄，并检查控制台只包含目标进程和探针自身，拒绝共享控制台。10 秒等待仅为本次实验观察窗口，不是正式产品默认超时。接口参考 Microsoft [AttachConsole](https://learn.microsoft.com/en-us/windows/console/attachconsole)、[WriteConsoleInput](https://learn.microsoft.com/en-us/windows/console/writeconsoleinput)。该传统控制台 API 不作为跨平台方案；当前只证明此 Windows 引擎构建下可用，M0-06 仍需比较 Ubuntu 和故障场景后固定实现。

### Windows 进程已创建、身份未落盘窗口

fault01 使用 `-FaultAfterStartBeforeIdentity`，在创建 Dota 后立即 Exit(73)。启动意图存在、process.json 不存在，Dota 继续加载 n7 并写独立日志。对同一 run 重新 launch 被已有 intent 拒绝，未重复派生。随后按精确可执行路径、唯一 cfg 参数和不早于 intent 的启动时间找到唯一候选，保存明确标为人工核验的身份，再通过持有句柄的正常 quit 退出（337 ms）。复核 PID 不存在、UDP 归属数 0，唯一 cfg 与归档哈希相同后已清理。

该结果证明中断窗口真实存在、保守禁止重试有效；没有实现全局自动恢复或宣称任意 PID 重用场景已覆盖。证据：`local/validation/windows/fault01/`。

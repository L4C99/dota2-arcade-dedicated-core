## 文件操作与本地客户端

A2S 在独立副本验证内容保留、备份、幂等、结构/值冲突、并发编辑检测、锁、链接、原生权限拒绝和各写入失败阶段。Windows 与 Ubuntu 普通用户原生测试通过。文件锁只协调本工具，外部编辑需在配置变更窗口停止，不能宣称通用文件 CAS 保证。普通启动不会隐式调用工具，详见 [A2S 说明](../a2s.md)。

公开 Go 客户端通过既定受限本地协议调用，示例使用同键重试传输超时、不自动改变请求意图。原生 Linux 客户端测试首次因测试临时目录过长失败；改用短随机目录后复测通过，程序路径限制未放宽，失败记录保留。修正后的 Windows 全量 go test ./... 与 go vet ./... 均通过。

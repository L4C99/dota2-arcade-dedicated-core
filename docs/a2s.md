# 独立 A2S 配置工具

```text
d2core a2s enable --dota-dir <游戏安装绝对路径> --json
```

仅检查并合并 game/dota/gameinfo.gi 的 GameInfo/GMS/Advertise 1。普通 create/restart 不调用此工具，不自动改变 VAC 或 gameinfo。工具不需要管理端运行。

返回 result.status：inserted（已插入并读回核验）、already_configured（已存在相同值，无新备份/改写）、conflict（原值不同、重复结构、锁或并发变化）、error（路径、权限或读写失败）。失败退出1，参数用法错误退出2；error对象提供原因。result.path为目标，实际准备备份时返回result.backup。

修改前将原始字节保存为同目录 gameinfo.gi.d2core-<原内容SHA256>.bak，独占创建并同步；同名备份必须逐字节匹配，否则拒绝。仅插入必要节点，保留原注释、换行与其他内容。UTF-8（允许BOM）、最大4MiB，结构歧义、指令/条件语法或非普通文件拒绝，不猜测修改位置；路径含链接时使用解析后的明确安装位置。

同目录独占锁协调本工具的并发执行；写临时文件并同步后，再核验源文件身份与内容未变，替换并读回核验。锁不替代系统级配置变更管理：执行期间不要同时运行安装更新或其他编辑器写入gameinfo。无法承诺阻止不遵守工具锁的外部程序在最终检查后写入；读回发现差异会报告冲突并保留备份。异常退出留下的锁不会自动删除，应先确认没有仍在执行的工具再人工处理。

失败不代表必然未写入：替换后验证或同步失败时保留备份并报告error，先检查文件，不盲目覆盖还原。需要回滚时先停止使用该配置的测试实例，核对当前文件及备份归属，再恢复已核验备份。Linux同步文件和目录；Windows使用写透替换，不以此宣称整机断电验收通过。

配置成功不代表运行中的引擎已生效。必须重启对应隔离测试服，并单独执行A2S查询；进房/就绪验证仍独立进行。已知同机共用客户端安装修改gameinfo可能影响安全握手，测试使用独立副本/挂载，不自动修改玩家共用安装或生产配置。

当前已通过双平台原生文件测试：内容保留、幂等、备份、结构/值冲突、并发编辑检测、原生写权限拒绝、链接拒绝、写入失败各阶段。Ubuntu 隔离配置下真实 A2S_INFO 查询已通过；Windows 早先独立路径试验查询超时，后在独立虚拟机安装上实际挑战及 A2S_INFO 查询通过，详见 [M4 记录](https://github.com/L4C99/dota2-arcade-dedicated-core/blob/main/docs/validation/m4.md)。

# 外部调用示例

`client` 是可供外部 Go 程序导入的同用户本地协议客户端；与 CLI 使用相同命名管道/Unix socket、身份检查、大小限制和超时处理。没有TCP管理端点，也不会替调用方启动管理端。

普通用户使用随包 launcher-example 二进制；这是集成演示，非生产常驻控制器。

开发者在源码仓库构建示例（部署用户无需执行）：

```sh
go build -o launcher-example ./examples/launcher
```

先显式启动核心serve，完成模板路径与地图准备，再运行：

```text
launcher-example --data-dir <绝对目录> --template <绝对模板路径> --key <唯一创建意图键> --connect-host <客户端可达主机名> --hold 30s
```

可选--port；省略自动分配。示例开房并等待本代就绪，打印ID、连接命令和少量原始日志，保留指定时长后stop，并查询终态确认回收。输出日志可能包含玩家信息，不应原样上传。NAT公网端口与内网端口不同的环境需由调用方转换连接信息，不能把通配监听当作公网地址。

遇到传输超时最多用相同键/参数重试3次，不生成新键；结构化拒绝不盲目重试。等待操作不超过5分钟，历史创建成功后仍检查当前状态。长启动超时配置或慢环境需相应调整调用方等待策略，不改变核心操作是否继续。

示例是可读的集成流程，不是常驻控制器。调用方取消或示例退出不会隐式停服；失败时保留已打印的实例/操作ID，查询原操作或显式stop。创建返回未知结果时保留--key与原参数重新查询，不能用新键掩盖不确定状态。核心过期删除历史后不再保证旧键去重，新意图始终使用新键。

独立程序可导入 `github.com/L4C99/dota2-arcade-dedicated-core/client`，调用 `New(dataDir)` 与 `Call(ctx, method, params)`；服务端拒绝是 `*client.Error`，网络/超时错误表示结果可能未知，不能当成未受理。协议字段见 [本地协议](../../docs/local-api.md)。示例真实专服闭环仍须按M4记录验收，编译成功不等于进房通过。

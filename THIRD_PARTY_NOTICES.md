This file accompanies both d2core and launcher-example distributions. This is an engineering inventory of the shipped Go build, not legal advice. Project-owned code is covered by LICENSE and LICENSING.md; dependencies retain their own licenses.

The CGO_ENABLED=0, Go 1.27.1 windows/amd64 and linux/amd64 dependency graphs were inspected with `go list -deps` for `./cmd/d2core` and `./examples/launcher`. The external modules are Microsoft/go-winio v0.6.2 (Windows only) and golang.org/x/sys v0.10.0 (both platforms). Go runtime/standard-library code and its vendored golang.org/x/net DNS code are also linked. Build tools and test-only code are not shipped.
